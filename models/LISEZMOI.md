# Modèles 3D

Tous viennent de Poly Haven (https://polyhaven.com), licence CC0 (domaine public), version glTF 1k. Les textures des petits objets ont été réduites à 512 px pour alléger le chargement.

| Dossier | Rôle dans la scène |
|---|---|
| `ArmChair_01` | bergères (grande salle et cabinet), reteintées en brun |
| `Ottoman_01` | pouf en cuir |
| `round_wooden_table_01` | table ronde du journal |
| `Lantern_01` | lanternes (table ronde, mezzanine) |
| `ladder_sectioned_01` | échelle de la mezzanine (sections empilées) |
| `fancy_picture_frame_01`, `fancy_picture_frame_02` | tableaux |
| `small_wooden_table_01` | bureau du cabinet (étiré aux dimensions du bureau) |
| `desk_lamp_arm_01` | lampe du bureau |
| `marble_bust_01` | buste sur la bibliothèque du cabinet |

Placement, teintes et tailles : fin de `scene.js`. Si un modèle ne se charge pas, l'objet équivalent construit par code reste affiché.
